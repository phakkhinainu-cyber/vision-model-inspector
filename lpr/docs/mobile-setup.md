# ดูผ่านมือถือและแท็บเล็ตแบบแอป (PWA) — ทั้งในบ้านและนอกบ้าน

ข้อมูลยังเก็บอยู่ในคอมที่บ้าน มือถือแค่ดึงมาแสดง ดังนั้นคอมต้องเปิดอยู่และต่อเน็ตไว้
**ห้ามเปิดพอร์ตที่เราเตอร์ (port forwarding) ให้อินเทอร์เน็ตเข้าคอมโดยตรง** — ใช้ Tailscale แทน

## วิธีที่ 1 (แนะนำ): Tailscale — ใช้ได้ทั้งในบ้านและนอกบ้าน มี HTTPS ให้อัตโนมัติ

Tailscale สร้างเครือข่ายส่วนตัวระหว่างอุปกรณ์ในบัญชีของคุณ ลิงก์จะเปิดได้เฉพาะเครื่องที่อยู่ในบัญชีของคุณเท่านั้น
แพ็กเกจส่วนตัวใช้ฟรี

### ที่คอมตรวจป้าย

1. ติดตั้ง Tailscale จาก https://tailscale.com/download/windows แล้วล็อกอิน (Google/Microsoft/Apple ก็ได้)
2. เปิดหน้า https://login.tailscale.com/admin/dns แล้วเปิด **MagicDNS** และ **HTTPS Certificates**
3. เปิด **Command Prompt** หรือ **PowerShell** (คลิกขวา → Run as administrator) แล้วพิมพ์:

   ```
   tailscale serve --bg 8765
   ```

   Tailscale จะแสดงลิงก์ เช่น `https://lpr-pc.tail1234.ts.net` (จำลิงก์นี้ไว้)
   - คำสั่งนี้จำค่าไว้และทำงานเองหลังรีสตาร์ตเครื่อง
   - ดูสถานะ: `tailscale serve status` · ยกเลิก: `tailscale serve --https=443 off`
4. (ไม่บังคับ) ในหน้าตั้งค่าของ LPR บ้าน → เครือข่าย → ปิด "เปิดให้มือถือในวง LAN เข้าถึง" ถ้าต้องการให้เข้าได้ทาง Tailscale เท่านั้น

### ที่มือถือ/แท็บเล็ต

1. ติดตั้งแอป **Tailscale** (App Store / Google Play) แล้วล็อกอินด้วย **บัญชีเดียวกับคอม** และเปิดสวิตช์เชื่อมต่อ
2. เปิดลิงก์ `https://ชื่อคอม.ชื่อเครือข่าย.ts.net` ที่ได้จากข้อ 3
3. ติดตั้งเป็นแอป:
   - **Android (Chrome)**: เมนูสามจุด → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
   - **iPhone / iPad (Safari)**: ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
4. เปิดแอป "LPR บ้าน" จากไอคอน → ล็อกอิน (ติ๊ก จำเครื่องนี้ไว้ 30 วัน)
5. เปิดการแจ้งเตือน: เมนู → ตั้งค่า → การแจ้งเตือน → **เปิดการแจ้งเตือนบนอุปกรณ์นี้** → อนุญาต
   - iPhone/iPad: ต้องเปิดจากไอคอนบนหน้าจอโฮม (iOS 16.4 ขึ้นไป) จึงจะรับ Web Push ได้
6. กด **ทดสอบ Web Push** (ต้องเป็น admin) เพื่อดูว่าแจ้งเตือนมาถึง

แจ้งเตือนจะส่งเมื่อพบรถ **ไม่รู้จัก**, **เฝ้าระวัง** หรือรถอยู่เกินเวลาที่ตั้ง (เปิด/ปิดแต่ละแบบได้ในหน้าตั้งค่า)

## วิธีที่ 2: ใช้ในบ้านอย่างเดียวด้วย self-signed certificate

ใช้เมื่อไม่อยากติดตั้ง Tailscale (ดูได้เฉพาะในวง Wi-Fi บ้าน)

1. ตั้งค่า → เครือข่ายและความปลอดภัย → เปิด **HTTPS ในบ้านด้วย self-signed certificate** → บันทึก → รีสตาร์ตเครื่อง
   (หรือ services.msc → LPR บ้าน → Restart)
2. หา IP ของคอม: เปิด Command Prompt พิมพ์ `ipconfig` ดูที่ IPv4 Address เช่น `192.168.1.50`
3. มือถือเปิด `https://192.168.1.50:8766` → เบราว์เซอร์จะเตือนว่าใบรับรองไม่น่าเชื่อถือ → เลือก ดำเนินการต่อ
4. ถ้าต้องการให้มือถือเชื่อถือถาวร (และให้ติดตั้งเป็นแอป/รับแจ้งเตือนได้) ให้ติดตั้งไฟล์
   `<ที่เก็บข้อมูล>\data\certs\lpr.crt` ลงในมือถือ:
   - Android: ตั้งค่า → ความปลอดภัย → การเข้ารหัสและข้อมูลรับรอง → ติดตั้งใบรับรอง → ใบรับรอง CA
   - iPhone: ส่งไฟล์ทาง AirDrop/อีเมล → ตั้งค่า → ดาวน์โหลดโปรไฟล์แล้ว → ติดตั้ง → ทั่วไป → เกี่ยวกับ → การตั้งค่าความเชื่อถือใบรับรอง → เปิด
5. ทำตามขั้นตอนติดตั้งแอปและเปิดการแจ้งเตือนเหมือนวิธีที่ 1

> HTTP ธรรมดา (`http://192.168.1.50:8765`) ใช้ดูข้อมูลในบ้านได้ แต่ติดตั้งเป็นแอปและรับแจ้งเตือนไม่ได้ เพราะ PWA ต้องใช้ HTTPS

## แจ้งเตือนทาง Telegram หรือ LINE (ทางเลือก)

**Telegram Bot**
1. ใน Telegram ค้นหา `@BotFather` → พิมพ์ `/newbot` → ตั้งชื่อ → จะได้ **token**
2. ส่งข้อความอะไรก็ได้หาบอทของคุณ 1 ครั้ง
3. เปิด `https://api.telegram.org/bot<token>/getUpdates` ในเบราว์เซอร์ หา `"chat":{"id":...}` = **chat id**
4. ตั้งค่า → การแจ้งเตือน → เปิด Telegram, ใส่ token และ chat id → บันทึก → ทดสอบ Telegram (ส่งภาพรถมาด้วย)

**LINE Messaging API** (LINE Notify ปิดบริการแล้วตั้งแต่ 31 มี.ค. 2568)
1. https://developers.line.biz → สร้าง Provider → สร้าง **Messaging API channel** (จะได้บัญชี LINE OA)
2. แท็บ Messaging API → ออก **Channel access token (long-lived)**
3. เพิ่มเพื่อน LINE OA ของคุณ, หา **user id** ของคุณที่แท็บ Basic settings (Your user ID) หรือใช้ group id
4. ตั้งค่า → การแจ้งเตือน → เปิด LINE, ใส่ token และ user id → บันทึก → ทดสอบ LINE

## ความปลอดภัย

- ทุกหน้าต้องล็อกอิน ล็อกอินผิดหลายครั้งจะถูกล็อกชั่วคราว
- ให้คนในบ้านใช้บัญชีสิทธิ์ **viewer** (ดูอย่างเดียว) — สร้างที่ ตั้งค่า → ผู้ใช้
- อัปเดต Windows และแอป Tailscale สม่ำเสมอ ห้ามเปิดพอร์ตเราเตอร์เข้าคอมโดยตรง
